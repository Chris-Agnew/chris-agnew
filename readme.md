### E-Commerce Operations · Onboarding & Implementation

I work in multichannel e-commerce: catalog and product data, marketplace integrations across Shopify, Amazon, and Walmart, inventory and pricing logic, and the automation that removes the manual parts.

Most of that is operations work. Growing storefronts, cleaning up product data, keeping supplier feeds and channel listings in sync, brand protection and Transparency on marketplaces, and site performance and accessibility. Lately it's implementation work on catalogs running into the hundreds of thousands of SKUs, with supplier feeds that rarely match their stated schema.

The technical side came along because the operations problems kept turning into technical ones. Day to day that looks like reading logs and API responses to find root cause, and writing requirements an engineering team can build from. What's public here is front-end work and a handful of utilities, mostly things I built to stop doing something by hand.

On the side I run **[CastQR](https://castqr.com)**, a QR code generator that charges once and makes static codes that can't expire. It came out of watching restaurants print a "free" code and find it dead on every table when the trial behind it ended. Every design is decoded in the browser before purchase to prove it scans. Cloudflare Workers, React Router, Stripe as merchant of record, no accounts.
